1. 리액트의 탄생
(1) 탄생 배경
- React는 페이스북의 개발팀이 화면 업제디이트를 위해 개발하던 중 탄생
- React 자바스크림트 기반의 라이브러리
- 2013년도에 등장한 선언형 방식으로 UI를 표현함
- 현재는 React. 19.v을 API 지원 : 항상 최신버전으로 개발 권장

(2) 왜 새로운 기술이 필요한가?
- 기존의 기술 한계점 발생이 생김 : 정적인 웹 구축에 초점, 대규모 앱 구축에 부적합했다.
- 페이스북의 요청사항은 : 
    - 다양한 인터렉션(사용자와의 양방향 소통)
    - 변화가 찾은 대규모 앱 필요
※ React의 핵심 목적: 변화가 자주 일어나는 대규모 애플리케이션에 적합한 쉽고 효율적인 라이브러리를 만들자!!

2. 리액트의 특징 3가지
(1) 컴포넌트 기반
    - UI를 독립적이고 재사용 가능한 컴포넌트 단위로 분리했다고 볼 수 있다(레고형태라 볼 수 있음).
(2) 가상돔(Virtual DOM)
    - 실제 DOM을 복제하여 가상DOM에서 필요한 부분만 업데이트를 진행한 후
    한번에 실제 DOM에 반영하여 빠른 업데이트를 진행함
(3) 단방향 데이터 흐름
    - 부모 컴퍼넌트에서 -> 자식 컴포넌트로 데이터를 전달함(○)
    - 자식 컴퍼넌트에서 -> 부모 컴포넌트로 데이터를 전달함(X)

3. React 앱 생성
(1) Vite(비트) - 리액트 라이브러리를 제공하는 오픈 API
(2) 기존 CRA(Create React App)를 대체하는 라이브러리
    - CRA는 2025년 기준 더이상 사용되지 않음(deprecated)
(3) Vite를 활용한 리액트 앱 생성
    1) 개발 환경 구성 - Node.js가 설치되어 있어야 함.
        ex) node -v, npm -v
    2) React 앱 생성 : my-App
        - 형식 : npn create vite@latest [앱이름(프로젝트명)]
        ex) npm create vite@latest my-app
